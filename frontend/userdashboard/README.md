# ✨ AI Pharmacy User Dashboard

A premium, patient-centric platform for effortless prescription management and pharmaceutical ordering.

---

## 🌟 Overview

the **User Dashboard** is the primary interface for patients to interact with the Autonomous Pharmacy System. It features a high-end, responsive design that prioritizes ease of use and visual clarity during the healthcare journey.

### Key Features
- **📸 Smart Prescription Upload**: Intuitive, chatbot-style interface for uploading medical prescriptions.
- **📦 Order Lifecycle Tracking**: Real-time updates on order processing, fulfillment, and delivery.
- **🔐 Secure Health Profile**: Encrypted storage for personal health records and prescription history.
- **✨ Cinematic UX**: Smooth transitions and interactive elements powered by Framer Motion.

---

## 🏗️ Architecture

Built on a cutting-edge frontend stack:
- **Framework**: React v19+ for maximum responsiveness.
- **Styling**: Tailwind CSS for a modern, utilities-first design approach.
- **Performance**: Vite v7+ for lightning-fast build and development cycles.

---

## 🚀 Quick Start

### Installation
```bash
# Install dependencies
npm install

# Start development server
npm run dev
```
